# GainzScore

> A gamified workout tracker where every rep earns XP — level up, climb the ranks, and dominate the leaderboard.

Built as a full-stack learning project combining a **Vue 3** SPA with a **Laravel 11** REST API.

---

## Features

- 💪 **Exercise Selector** — categorized modal (Chest, Back, Arms, Legs) with real DB data
- 📋 **Live Workout Tracker** — add sets, log weight & reps, mark completion
- ⭐ **XP & Leveling System** — earn XP per completed set, calculated with exercise multipliers
- 🏆 **Global Leaderboard** — ranked by total accumulated XP
- 🔐 **Auth** — registration, login, and logout via Laravel Sanctum tokens

## Getting Started

### Prerequisites

- PHP 8.2+, Composer
- Node.js 18+, pnpm

### 1. Clone

```bash
git clone https://github.com/your-username/gainzscore.git
cd gainzscore
```

### 2. Backend setup

```bash
cd backend
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate:fresh --seed   # creates SQLite DB + demo data
php artisan serve                  # runs on http://localhost:8000
```

### 3. Frontend setup

```bash
cd frontend
pnpm install
pnpm dev                           # runs on http://localhost:5173
```

### 4. Run both with one command (from project root)

```bash
pnpm install
pnpm dev
```

## API Overview

All mutating endpoints require a `Bearer` token obtained from `/api/login` or `/api/register`.

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| `POST` | `/api/register` | — | Create account, returns Sanctum token |
| `POST` | `/api/login` | — | Authenticate, returns Sanctum token |
| `POST` | `/api/logout` | ✅ | Revoke current token |
| `GET` | `/api/exercises` | — | List all exercises |
| `GET` | `/api/ranking` | — | Global leaderboard |
| `GET` | `/api/home-stats` | — | Aggregate workout count and XP |
| `GET` | `/api/users/{id}` | ✅ | User XP profile |
| `DELETE` | `/api/users/{id}` | ✅ | Delete own account |
| `POST` | `/api/workouts/start` | ✅ | Open a new workout session |
| `POST` | `/api/workouts/finish` | ✅ | Save completed workout + award XP |
| `GET` | `/api/users/{id}/workouts` | ✅ | Workout history (own only) |
| `POST` | `/api/sets/log` | ✅ | Log a single set |
